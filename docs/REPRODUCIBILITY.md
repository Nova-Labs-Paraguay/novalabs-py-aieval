# Reproducibility

Run `npm install`, `npm run typecheck`, `npm test`, and `npm run verify:release`. The Stage 1 artifact must validate to SHA-256 `4ffddc7fa09c5092258a632f79fb051e3b82ddbd142fad1383578a9c8491858d`. Raw system prompts are not persisted in run manifests; only `systemPromptHash` is retained.
